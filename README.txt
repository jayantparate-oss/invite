CURIOUSJR - THE SECRET OF SUCCESS
Open via a local or hosted HTTP server. Example: in this folder run python -m http.server 8000, then open http://localhost:8000. Internet access is needed for the pinned Three.js CDN module. Set window.EVENT_JOIN_URL in index.html to the actual event URL. Original procedural 3D assets are used; no official GTA or CuriousJr mascot/logo files are included. Countdown is based on device clock and the fixed IST timestamp. Sound is optional synthesized effects. The project uses native JS and Three.js rather than React/GSAP. No browser runtime testing was performed.
